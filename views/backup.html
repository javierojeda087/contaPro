Información de Seguridad y Restauración
  • Los archivos `.sql` contienen las sentencias DDL (tablas, secuencias, funciones, vistas) y todas las consultas INSERT con COMMIT de la base de datos Oracle.
  • Las copias de seguridad se almacenan automáticamente en la carpeta /backups del servidor.
  • Para restaurar un backup en la base de datos, puede ejecutar el archivo SQL directamente desde Oracle SQL Developer, SQL*Plus o la herramienta Command Prompt del sistema.
